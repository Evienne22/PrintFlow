# PrintFlow

Sistema de gestión para emprendimientos de impresión.

## Objetivo

PrintFlow nace como un proyecto de aprendizaje y evolución profesional.
La idea es desarrollar una herramienta para gestionar clientes,
pedidos, costos y producción de trabajos de impresión.

## Tecnologías

- Python
- Git
- GitHub
